# Minimal Market

Минималистичный маркетплейс для покупки и продажи вещей.

**Демо:** [https://minimal-market-ten.vercel.app](https://minimal-market-ten.vercel.app/)

## Возможности
### Каталог и товары

- поиск по названию, бренду и категории;
- фильтр по категориям со счётчиками товаров;
- фильтр по цене («от» и «до») и переключатель «Только в наличии»;
- сортировка: сначала новые, сначала дешёвые, сначала дорогие;
- постраничная навигация (по 12 товаров на странице);
- все фильтры, сортировка и номер страницы хранятся в адресной строке, поэтому ссылкой на выдачу можно поделиться;
- страница товара: галерея с несколькими фотографиями, бренд, артикул, цена и старая цена, остаток на складе, название магазина продавца;
- рейтинг и отзывы к товарам;
- жалоба на товар или на отзыв.

### Покупки

- избранное;
- корзина: изменение количества (не больше остатка на складе), удаление позиций, очистка корзины, предупреждение, если товара в наличии меньше, чем в корзине;
- оформление заказа с адресом и телефоном; перед созданием заказа проверяются актуальные цены и остатки, при изменении цены пользователь видит новую сумму и подтверждает заказ повторно;
- страница «Мои заказы»: состав, адрес, статус и итоговая сумма; оплата (имитация) и отмена заказа, при отмене товары возвращаются на склад;
- личный кабинет со ссылками на заказы, избранное и корзину.

### Кабинет продавца

- публикация товара: название, категория, бренд, цена, остаток, описание и фото (JPG, PNG или WebP до 5 МБ);
- вкладка «Товары»: быстрое изменение цены, старой цены, остатка и статуса (активен, черновик, скрыт);
- вкладка «Заказы»: позиции заказов на товары продавца с адресом доставки и кнопкой перевода в следующий статус;
- вкладка «Статистика»: выручка, число проданных штук и заказов, средний чек, пять лучших товаров и список товаров, которые заканчиваются (остаток не больше 3 шт.).

### Админ-панель

- **Жалобы:** просмотр жалоб на товары и отзывы; можно скрыть товар, удалить отзыв, отметить жалобу решённой или отклонить её;
- **Продавцы:** назначение и снятие роли продавца, название магазина;
- **Категории:** добавление, переименование и удаление;
- **Все заказы:** просмотр заказов всех покупателей.

### Аккаунты и безопасность

- регистрация и вход по email и паролю (Supabase Auth); поддерживается подтверждение почты, если оно включено в Supabase;
- после входа пользователь возвращается на страницу, с которой его перенаправили на авторизацию;
- три роли: покупатель, продавец (назначает администратор) и администратор;
- страницы закрыты компонентами `RequireAuth`, `RequireSeller`, `RequireAdmin`;
- защита данных на уровне базы: удалять и менять товар может только его владелец;
- страница 404 для несуществующих адресов.

## Запуск локально

1. Установите [Node.js](https://nodejs.org) (LTS-версия).
2. Склонируйте репозиторий и установите зависимости:

```bash
   git clone https://github.com/aidar0x/minimal-market.git
   cd minimal-market
   npm install
```

3. Создайте проект на [supabase.com](https://supabase.com) и выполните SQL из файла
   `supabase/schema.sql` (раздел **SQL Editor**).
4. В Supabase откройте **Authentication → Sign In / Providers → Email** и на время
   разработки отключите **Confirm email**.
5. Скопируйте `.env.example` в `.env.local` и вставьте свои значения из
   **Project Settings → API**:

```text
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your_public_anon_key
```

6. Запустите проект:

```bash
   npm run dev
```

   Сайт откроется на `http://localhost:5173`.

## Роли

| Роль | Как получить | Что доступно |
|---|---|---|
| Покупатель | регистрация | каталог, избранное, корзина, заказы, отзывы, жалобы |
| Продавец | назначает администратор | кабинет продавца, публикация и управление своими товарами |
| Администратор | задаётся в базе данных | админ-панель: жалобы, продавцы, категории, все заказы |

## Скрипты

| Команда | Что делает |

| `npm run dev` | запуск в режиме разработки |

| `npm run preview` | предпросмотр собранной версии |
| `npm run lint` | проверка кода линтером oxlint |

## Деплой

Проект публикуется на Vercel. В настройках проекта заданы переменные окружения
`VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Файл `vercel.json` настраивает
перенаправление всех адресов на `index.html` для работы React Router.
